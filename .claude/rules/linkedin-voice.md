# LinkedIn Voice

Rules for *how* to write a LinkedIn post about this repo. For *what* the post should be about (repo purpose, what's currently being worked on), see the "Content" section in [CLAUDE.md](../../CLAUDE.md).

## Tone

Casual, conversational, first person — like explaining what I built to a peer, not a press release. Avoid corporate/marketing voice ("thrilled to announce", "excited to share").

## Length & Structure

Medium length: a handful of short paragraphs, separated by line breaks for scannability. One core idea developed per post — not a listicle, not a multi-topic thread. Get to the point quickly; don't bury the idea under a long wind-up.

## Avoid

- Humble-bragging or "hustle"/grind-culture framing — no "the grind never stops," no fishing for validation.
- Self-congratulatory tone. State what was built/learned plainly; let it speak for itself.

## Unresolved (ask if it matters for a given post)

- Emoji and hashtag usage haven't been specified yet — default to none unless told otherwise for a given post.
- No fixed opening/closing pattern defined yet — update this file once one emerges.
